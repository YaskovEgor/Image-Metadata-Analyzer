Metadata Analyzer

Описание

Metadata Analyzer - десктопное приложение для извлечения и анализа скрытых метаданных из изображений. Программа парсит EXIF-блоки, декодирует бинарные теги и конвертирует GPS-координаты из формата градусы/минуты/секунды (DMS) в десятичные градусы (DD) с последующей интеграцией с Яндекс.Картами.

Функциональность

- Извлечение EXIF-данных (модель камеры, выдержка, ISO, диафрагма, дата съёмки)
- Декодирование GPS-координат с конвертацией DMS -> DD и учётом полушарий (N/S/E/W)
- Открытие точного местоположения на Яндекс.Картах
- Копирование координат в буфер обмена
- Экспорт всех метаданных в JSON
- Асинхронная загрузка изображений через threading (UI не блокируется)
- Поддержка форматов: JPEG, PNG, BMP, TIFF, WEBP
- Горячие клавиши: Ctrl+O (открыть), Ctrl+C (копировать из активной вкладки)

Технологии

- Python 3.11
- Tkinter / ttk (GUI)
- Pillow (работа с изображениями и EXIF)
- threading (асинхронная загрузка)
- JSON (экспорт данных)

Технические детали

EXIF-данные извлекаются через низкоуровневый метод _getexif() библиотеки Pillow. Бинарные теги декодируются с учётом кодировки UTF-8. GPS-координаты, хранящиеся в формате (градусы, минуты, секунды) + текстовое поле полушария, преобразуются в десятичные градусы по формуле: degrees + (minutes/60) + (seconds/3600).

Для предотвращения зависания интерфейса при обработке больших файлов (TIFF до 50+ МБ) используется отдельный поток с ProgressBar. Обновление GUI выполняется через root.after().

Запуск производится через файл Metadata Analyzer.exe

Использование

Запустите приложение

Нажмите "Открыть изображение" или Ctrl+O

Выберите файл (JPEG, PNG, TIFF и др.)

Просмотрите EXIF-данные на первой вкладке

При наличии GPS перейдите на вкладку "GPS координаты"

Нажмите "Открыть в Яндекс.Картах" для просмотра места съёмки

Для сохранения метаданных нажмите "Сохранить метаданные" или перейдите на вкладку "Все данные (JSON)"
